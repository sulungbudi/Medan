Pembuka

Tujuan pelatihan

Pelatihan ini mengajak guru mengalami sendiri cara belajar STEM sebagai proses: merancang, membuat, menguji, dan memperbaiki. Alatnya adalah coding dengan bantuan AI dan pengukuran nyata dengan webcam.

Di akhir pelatihan, setiap guru memiliki:

Akun GitHub aktifTerdaftar dengan Gmail masing-masing.
Website pribadiOnline di alamat username.github.io.
Web-app buatan sendiriDibangun bersama AI, siap dipakai di kelas.

Sesi 1

STEM dan belajar proses dengan cepat

STEM adalah proses, bukan kumpulan fakta

Ilmuwan dan insinyur bekerja dalam siklus yang terus diulang:

Bertanya→ Memodelkan→ Membuat / mengukur→ Menguji→ Memperbaiki↺

Di kelas, siswa sering hanya menerima hasil akhir siklus ini (rumus jadi), tanpa menjalani siklusnya. Dalam pendekatan proses, kesalahan bukan kegagalan, melainkan data untuk memperbaiki model.

Feedback cepat berarti belajar lebih cepat

Lab konvensionalDengan coding
Waktu satu siklusLama: siapkan alat, ukur, olah data manualDetik: ubah satu baris, hasil langsung tampil
Siklus per pertemuan*±1 kalipuluhan kali
Biaya mencoba "bagaimana jika...?"Mahal (alat, bahan, waktu)Hampir nol

*Angka ilustratif untuk menggambarkan besarnya perbedaan, bukan hasil penelitian.

Pesan kunciSiklus yang pendek membuat siswa berani menebak dan mencoba. Feedback yang cepat mengubah siswa dari penonton menjadi peneliti.

Dua jenis feedback

Feedback dari kodeProgram berjalan atau error; hasil tampil seketika. Melatih berpikir logis, tetapi hanya menguji logika program.
Feedback dari alamData cocok dengan model atau tidak. Inilah inti sains. Lebih lambat, tetapi menentukan kebenaran.

Simulasi saja berisiko membuat siswa percaya pada model yang salah karena tampilannya meyakinkan. Karena itu pelatihan ini menggabungkan keduanya: kode yang mengukur alam (Sesi 4).

Relevansi dengan kelas saat ini

  • Kurikulum Merdeka: pembelajaran mendalam berbasis proyek dan pengalaman nyata.
  • Projek P5: menghasilkan produk nyata secara kolaboratif.
  • Mapel Koding dan Kecerdasan Artifisial: literasi coding dan AI yang kini masuk ke sekolah.
  • Lintas mata pelajaran: Fisika, Kimia, Biologi, Matematika, bahkan mapel non-sains.

Sesi 2

Akun GitHub dan website pertama

Konsep dasar

RepositoriFolder online untuk menyimpan kode beserta riwayat perubahannya.
GitHub PagesHosting website gratis, langsung dari repositori.
HTTPS otomatisAlamat aman; syarat agar browser mengizinkan akses webcam.

Alamat website setiap guru berbentuk https://username.github.io.

Langkah 1: mendaftar GitHub dengan Gmail

  1. Buka github.com/signup.
  2. Masukkan alamat Gmail Anda.
  3. Buat password yang kuat.
  4. Pilih username: huruf kecil, tanpa spasi, singkat, dan profesional (misalnya sarifisika).
  5. Selesaikan puzzle verifikasi.
  6. Masukkan kode yang dikirim ke Gmail. Jika diminta memilih paket, pilih Free.
TipsUsername akan menjadi alamat website, jadi pilih dengan hati-hati. Buka Gmail di HP agar kode verifikasi mudah dicek; periksa folder Spam atau Promosi bila kode tidak datang. Catat username dan password.

Langkah 2: membuat repositori website

  1. Klik tanda + di kanan atas, pilih New repository.
  2. Isi nama repositori: username.github.io (ganti username dengan username Anda).
  3. Pilih Public dan centang Add a README file.
  4. Klik Create repository.
PentingNama repositori harus persis sama dengan username diikuti .github.io. Salah satu huruf saja, website tidak akan muncul.

Langkah 3: membuat halaman utama index.html

  1. Di repositori, klik Add file → Create new file.
  2. Beri nama file index.html (huruf kecil semua).
  3. Tempel kode di bawah ini, ganti judul dan isinya, lalu klik Commit changes.
<!doctype html>
<html lang="id">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Kelas Bu Sari</title>
</head>
<body>
  <h1>Selamat datang!</h1>
  <p>Website kelas Fisika.</p>
</body>
</html>

Langkah 4: mengaktifkan website

  1. Buka Settings → Pages.
  2. Pada Branch, pilih main dan folder /(root), lalu klik Save.
  3. Tunggu 1–2 menit, lalu buka https://username.github.io di browser atau HP.

Untuk repositori bernama username.github.io, Pages biasanya sudah aktif otomatis; langkah ini memastikan sumbernya cabang main.

Kendala yang sering muncul

MasalahPenyebab umum dan solusi
Error 404Nama repositori tidak sama persis, atau file bernama Index.html (huruf besar). Perbaiki, lalu tunggu beberapa menit.
Perubahan belum tampilGitHub Pages butuh 1–2 menit; browser menyimpan versi lama. Tekan Ctrl+F5 atau buka di mode penyamaran.
Kode verifikasi tidak datangPeriksa folder Spam/Promosi di Gmail, lalu kirim ulang kode.
Lupa passwordPilih Forgot password dan gunakan Gmail yang sama.

Sesi 3

Web-app dengan bantuan AI

Alur kerja

Ide→ Prompt→ Kode→ Uji→ Perbaiki↺ Unggah

Mulailah dari masalah nyata di kelas. Hasil pertama AI jarang sempurna, dan itu normal: siklus prompt → uji → perbaiki adalah siklus STEM itu sendiri. Guru tidak harus menjadi programmer; peran guru adalah merancang ide dan menguji kebenarannya.

AI yang bisa dipakai: DeepSeek (chat.deepseek.com), atau alternatif seperti ChatGPT, Claude, dan Gemini. Prompt yang sama dapat dipakai di semua layanan tersebut.

Template prompt

Ganti bagian dalam kurung siku sesuai kebutuhan. Semakin spesifik, semakin baik hasilnya.

Buatkan web-app dalam SATU file HTML
(HTML, CSS, dan JavaScript digabung),
tanpa server dan tanpa instalasi.

Tujuan  : [kuis 10 soal gerak lurus]
Pengguna: siswa SMA, dipakai di HP
Fitur   : 1) [...]  2) [...]  3) [...]

Tampilan sederhana dan rapi.
Semua teks dan komentar kode dalam bahasa Indonesia.

Kiat berinteraksi dengan AI

  • Tambah satu fitur per langkah. Uji dulu sebelum meminta fitur berikutnya.
  • Salin pesan error persis ke AI, misalnya: "Muncul error ini: ... Tolong perbaiki."
  • Minta penjelasan kode bagian demi bagian agar Anda memahami cara kerjanya.
  • Simpan versi yang sudah berhasil sebelum meminta perubahan besar.

Ide web-app untuk berbagai mapel

Pengacak kelompokBagi siswa ke kelompok acak dari daftar nama.
Kuis interaktifSkor dan pembahasan muncul otomatis.
Simulasi fisikaGerak parabola, rangkaian listrik, gelombang.
Kalkulator kimiaMassa molar, pengenceran, stoikiometri.
Grafik fungsiGeser parameter, amati perubahan grafik.
Timer kelasPresentasi, diskusi kelompok, kuis cepat.

Mengunggah web-app ke GitHub

  1. Simpan kode dari AI sebagai file berakhiran .html, misalnya kuis.html (huruf kecil, tanpa spasi).
  2. Di repositori: Add file → Upload files. Alternatif: Create new file, lalu tempel kodenya.
  3. Klik Commit changes, tunggu 1–2 menit.
  4. Buka di https://username.github.io/kuis.html.

Agar beranda menjadi "etalase" kelas, tambahkan tautan ke setiap aplikasi di index.html:

<ul>
  <li><a href="kuis.html">Kuis Gerak Lurus</a></li>
  <li><a href="fungsi.html">Grafik Fungsi Interaktif</a></li>
  <li><a href="pelacak.html">Pelacak Gerak</a></li>
</ul>

Memakai AI secara bertanggung jawab

Periksa kebenaranAI bisa salah rumus, satuan, atau konsep dengan nada sangat yakin. Uji web-app dengan soal yang jawabannya sudah diketahui.
Lindungi data siswaJangan tempelkan nama, nilai, atau data pribadi siswa ke AI. Gunakan data contoh.
Jujur soal AICantumkan "dibuat dengan bantuan AI" pada aplikasi; ini juga contoh baik bagi siswa.
Siapkan cadanganJika DeepSeek sibuk, gunakan ChatGPT, Claude, atau Gemini dengan prompt yang sama.

Sesi 4

Pelacak gerak dengan webcam

Bagaimana komputer "melihat" gerak

  1. Kamera merekam video, yaitu deretan gambar diam (±30 gambar per detik).
  2. Setiap gambar tersusun dari piksel; tiap piksel punya nilai merah, hijau, biru (0–255).
  3. Pengguna mengklik benda untuk menentukan warna target.
  4. Program mencari semua piksel yang warnanya mirip target, lalu menghitung titik pusatnya.
  5. Posisi titik pusat dicatat bersama waktunya, sehingga diperoleh data posisi terhadap waktu.

Titik pusat adalah rata-rata posisi seluruh N piksel yang cocok, konsep yang sama dengan pusat massa:

x = Σxi / N,    y = Σyi / N

Membangun pelacak dengan prompt bertahap

Jangan meminta semuanya dalam satu prompt. Bangun bertahap dan uji setiap tahap.

TahapContoh prompt
1. Tampilkan webcam"Buat halaman HTML yang menampilkan video webcam di sebuah canvas."
2. Lacak warna"Saat saya klik benda, simpan warnanya dan tandai posisi benda itu."
3. Rekam data"Tambah tombol Rekam: catat waktu dan posisi, tampilkan grafik y terhadap t."
4. Kalibrasi"Ubah piksel ke meter: klik dua ujung penggaris lalu masukkan panjangnya."
5. Analisis"Hitung percepatan dengan fit kuadratik dan sediakan unduhan CSV."
Kamera butuh HTTPSBrowser hanya mengizinkan akses kamera di alamat aman. Jika kamera tidak mau menyala saat file dibuka langsung dari komputer, unggah dulu ke GitHub Pages lalu buka dari alamat https://username.github.io/....

Eksperimen: mengukur percepatan gerak jatuh

Persiapan:

  • Kamera diam (tripod atau tumpukan buku), menghadap tegak lurus bidang gerak.
  • Latar polos dan pencahayaan terang serta merata.
  • Bola berwarna mencolok (merah, hijau neon, atau biru).
  • Penggaris 30 cm di bidang gerak untuk kalibrasi.

Langkah: pilih warna bola, kalibrasi dengan penggaris, tekan Rekam, jatuhkan bola dari ±1 m, lalu tekan Stop.

Analisis: grafik y(t) berbentuk parabola. Dengan fit kuadratik

y = a + bt + ct2  ⇒  percepatan = 2c

Hasilnya mendekati −9,8 m/s², tetapi hampir tidak pernah tepat. Diskusikan dengan siswa: mengapa? Inilah momen sains yang sesungguhnya. Sebagai gambaran, bola yang jatuh 1 m hanya butuh ±0,45 s, sehingga pada 30 fps hanya terekam ±14 titik data.

Batasan yang perlu dipahami

  • Frame rate ±30 fps: gerak cepat menjadi kabur dan titik data sedikit.
  • Pencahayaan mengubah warna benda yang terlihat kamera.
  • Perspektif: benda harus bergerak sejajar bidang kamera; benda yang mendekat/menjauh membuat kalibrasi tidak berlaku.
  • Ketelitian kalibrasi menentukan ketelitian hasil.

Batasan ini bukan kelemahan yang perlu disembunyikan, melainkan bahan diskusi tentang ketidakpastian pengukuran.

Ide eksperimen lanjutan

FisikaPeriode bandul, lintasan parabola, GLB/GLBB troli di bidang miring, osilasi pegas dan redamannya.
KimiaPerubahan warna larutan pada titrasi atau laju reaksi.
BiologiPergerakan organisme kecil atau pertumbuhan tanaman (time-lapse).

Contoh

Contoh web-app

Dua contoh web-app berikut dibuat dengan bantuan AI dan dapat dibuka, dipelajari, serta dimodifikasi:

Pelacak GerakLacak benda berwarna dengan webcam, kalibrasi, rekam, grafik, fit kuadratik, unduh CSV. Grafik Fungsi InteraktifLinear, kuadrat, sinus, eksponen, logaritma, ReLU, dan fungsi bebas dengan parameter yang dapat digeser.

Catatan tentang Grafik Fungsi Interaktif

  • Tombol ▶ pada tiap parameter menganimasikan parameter tersebut.
  • Simpan sebagai pembanding menampilkan grafik sebelumnya sebagai garis putus-putus.
  • Pada fungsi bebas, gunakan tanda * untuk perkalian dan ^ untuk pangkat. Tersedia sin, cos, tan, sqrt, abs, exp, ln, log10, max, min, pi, dan ReLU. Boleh ditulis dengan awalan, misalnya y = ReLU(x).
  • ReLU(z) = max(0; z) adalah fungsi aktivasi pada jaringan saraf tiruan. Coba ReLU(a*x + b) - ReLU(c*x + d): beberapa ReLU yang dijumlahkan dapat membentuk kurva yang rumit dari potongan garis lurus, prinsip yang dipakai AI.

Referensi

Daftar istilah

HTML, CSS, JavaScript
Tiga bahasa penyusun halaman web: isi (HTML), tampilan (CSS), dan perilaku/logika (JavaScript).
Repositori
Folder proyek di GitHub yang menyimpan file beserta riwayat perubahannya.
Commit
Menyimpan perubahan ke repositori, disertai catatan singkat.
GitHub Pages
Layanan GitHub untuk menayangkan isi repositori sebagai website.
HTTPS
Protokol web yang aman; wajib agar browser mengizinkan akses kamera.
Prompt
Instruksi atau pertanyaan yang diberikan kepada AI.
Piksel
Titik terkecil penyusun gambar digital, masing-masing dengan nilai warna RGB.
fps (frame per second)
Jumlah gambar yang direkam kamera setiap detik.
Kalibrasi
Menghubungkan satuan alat ukur (piksel) dengan satuan fisika (meter).
Fit kuadratik
Mencari persamaan parabola yang paling cocok dengan data.
CSV
Format tabel teks sederhana yang bisa dibuka di Excel, Google Sheets, atau Python.
ReLU
Rectified Linear Unit, max(0; z): fungsi aktivasi yang banyak dipakai di jaringan saraf tiruan.
